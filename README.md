# Personal Portfolio Website

Practice/academic web-development project built with HTML, CSS and JavaScript.

## Features
- Responsive design
- Sticky navigation and mobile menu
- About, skills, projects and contact sections
- Simple JavaScript interaction

## Run
Open `index.html` in a browser, or use VS Code Live Server.

## GitHub
Create a repository named `personal-portfolio-website` and upload these files. Replace the sample contact links before publishing.
